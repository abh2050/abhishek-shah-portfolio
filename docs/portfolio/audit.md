# Baseline audit

- Repository: `abh2050/abhishek-shah-portfolio`
- Baseline commit: `5a0b3da9f48a2a1942cb21b75fc45cb25efcb889` ("Updated hero title & subtitle")
- Audited: 2026-10-01
- Stack at baseline: React 18, TypeScript, Vite 5, Tailwind, shadcn/ui, HashRouter, GitHub Pages via Actions. Generated by Lovable.

## Findings

| Area | Finding | Resolution |
|---|---|---|
| Career facts | FAQ and chatbot copy listed BMW as the current employer; SSOE Group was missing or inconsistent. | Shared `profile`/`experience` content; `check:content` asserts SSOE is the only current role and the title matches everywhere. |
| Résumé | Repository DOCX and the linked Google Doc PDF both listed BMW as current. | Neither published. Owner-supplied `Profile.pdf` (2026-10-01) published as `public/resume/Abhishek-Shah-Resume.pdf`. |
| Chatbot | `VirtualAbhishekChatBotSimple` answered from hard-coded, stale text and presented itself as a "trained AI assistant". | Removed; replaced by explicit FAQ backed by shared content. |
| Mobile navigation | Menu toggle targeted the desktop nav; no focus management, Escape handling, or route dismissal. | Radix dialog with focus trap, Escape, focus return, close on route change and on resize to desktop, scroll lock. |
| Metadata | `og:image`/`twitter:image` malformed (Lovable preview URL concatenated with `<your-repo>` placeholder); generic "Senior Data Scientist" description; `YOUR_SPOTIFY_USERNAME` placeholder in content. | New metadata, JSON-LD, 1200×630 social card, SVG favicon; content check rejects placeholder strings. |
| Projects | Single 1,063-line `Portfolio.tsx` with unsourced claims and stock imagery (Getty, AI-generated). | Six typed case studies with evidence links at pinned commits; 15 provenance-tracked assets; stock images removed. |
| Assets | 20 unoptimised images in `public/assets`, several unused, no attribution. | Optimised WebP outputs with intrinsic sizes, SHA-256 and rights recorded in `docs/portfolio/assets.json`. |
| Docs | README was the Lovable template. | Rewritten; see `README.md`. |
| Dependencies | `bun.lockb` alongside npm lockfile. | npm only; Vite 6.4 and React Router 7 (security advisories), Node 24 pinned in `.nvmrc` and CI. |
